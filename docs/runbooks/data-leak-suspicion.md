# Runbook: подозрение на утечку секретов или данных

Действия:
1. Немедленно revoke токены, выданные POST /v1/... (Short-lived по design).
2. Составить отчёт по audit-log проекта (hash-chain подтвердит целостность событий).
3. Сканировать связанные артефакты (gitleaks/trivy) до повторного ввода в строй.
4. Активировать project data-классификацию RESTRICTED: запрет внешних провайдеров (R-20).
5. Всё, что изменилось — фиксировать в Incident API для PSLC-отчёта и регресс-теста.
